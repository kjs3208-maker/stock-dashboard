# 주식 관리 대시보드

보유 종목, 손익 현황, 포트폴리오 통계를 한눈에 확인할 수 있는 개인용 주식 관리 대시보드입니다.

## 주요 기능

- **보유 종목 목록 및 손익 현황**: 종목별 수량 / 매입가 / 현재가 / 평가금액 / 평가손익 / 수익률
- **포트폴리오 요약 통계**: 총 평가금액, 총 매입금액, 평가손익, 최고·최저 수익률 종목, 당일 등락
- **종목 추가 / 수정 / 삭제**: 브라우저 로컬 스토리지에 저장 (별도 서버/DB 불필요)
- **자산 배분 차트**: 종목별 보유 비중 (8개 초과 시 "기타"로 통합)
- **연도별 포트폴리오 수익률 차트**: 매입 연도부터 현재까지 연도별 수익률
- **가격 추이 차트**: 선택한 종목의 최근 5년 일별 종가
- **관련 최근 뉴스**: 종목별 최근 뉴스 + 간단한 호재/악재/중립 태그

## 기술 스택

Next.js(App Router) · TypeScript · Tailwind CSS · Recharts

## 실시간 데이터 연동에 대해

가격/뉴스 API는 서버 사이드 라우트(`/api/quote`, `/api/history`, `/api/news`)에서
Yahoo Finance의 비공식 엔드포인트를 호출합니다. 별도의 API 키가 필요 없지만
비공식 엔드포인트이므로 언제든 변경되거나 요청이 실패할 수 있습니다.

**실시간 조회가 실패하면 자동으로 시드 기반 모의(mock) 데이터로 대체되어
대시보드가 항상 정상적으로 동작합니다.** 이 경우 해당 데이터에 `MOCK` 표시가
붙습니다. (샌드박스처럼 외부 네트워크가 차단된 환경에서는 항상 모의 데이터로
표시됩니다 — 로컬 PC나 일반적인 배포 환경에서 실행하면 실시간 데이터가 정상적으로
연동됩니다.)

뉴스는 Yahoo Finance 검색 API의 뉴스 결과를 사용하며, 별도의 감성분석 API 없이
제목의 키워드를 기반으로 호재/악재/중립을 간단히 분류합니다(`lib/sentiment.ts`).
더 정교한 분석이 필요하면 이 함수를 원하는 LLM/NLP API 호출로 교체하면 됩니다.

## 알려진 제한사항

- **환율 미반영**: 여러 통화(KRW/USD 등)의 종목을 함께 보유하면 포트폴리오 요약과
  연도별 수익률은 환율 변환 없이 단순 합산되어 근사치로 표시됩니다. 화면에 경고
  문구가 표시됩니다.
- **로컬 저장**: 보유 종목 데이터는 브라우저의 `localStorage`에만 저장됩니다.
  기기/브라우저를 바꾸면 데이터가 유지되지 않습니다.

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 접속.

프로덕션 빌드:

```bash
npm run build
npm run start
```
